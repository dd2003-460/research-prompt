# 研究 prompt 20 分制 Rubric

> origin: ai · 2026-10-23 20:35 · 版本 v1.0
> 用途：给研究 prompt 生成的研究结果打分，对照 decomp 的 18 分制（C0 契约）

## 评分维度

### 1. 缺失信息识别（4 分）

| 分数 | 标准 |
|------|------|
| 4 | 所有黑盒节点都识别出，且优先级排序正确（瓶颈 > 次要因素 > 背景知识） |
| 3 | 大部分黑盒节点识别出，但优先级排序有误（次要因素排在瓶颈之前） |
| 2 | 一半黑盒节点识别出，另一半遗漏 |
| 1 | 只有少数黑盒节点识别出（<50%） |
| 0 | 没有识别出任何黑盒节点 |

### 2. 矛盾挖掘（4 分）

| 分数 | 标准 |
|------|------|
| 4 | 所有主要矛盾都挖出，且每个矛盾的验证路径清晰（能照着做） |
| 3 | 大部分主要矛盾挖出（80%+），但验证路径不够清晰 |
| 2 | 一半主要矛盾挖出（50-80%） |
| 1 | 只有少数主要矛盾挖出（<50%） |
| 0 | 没有挖出任何矛盾 |

### 3. 推理与计算（4 分）

| 分数 | 标准 |
|------|------|
| 4 | 所有关键指标都有完整计算链（公式 + 代入 + 结果 + 单位 + 误差），且单位一致性检查通过 |
| 3 | 大部分关键指标有计算链（80%+），但缺少误差范围 |
| 2 | 一半关键指标有计算链（50-80%） |
| 1 | 只有少数关键指标有计算链（<50%） |
| 0 | 没有计算链，只给结论 |

### 4. 产投比评估（4 分）

| 分数 | 标准 |
|------|------|
| 4 | 所有方案的投入/产出/产投比都计算正确，且排序正确 |
| 3 | 大部分方案的产投比计算正确（80%+），但排序有误 |
| 2 | 一半方案的产投比计算正确（50-80%） |
| 1 | 只有少数方案的产投比计算正确（<50%） |
| 0 | 没有计算产投比 |

### 5. 风险与方差（2 分）

| 分数 | 标准 |
|------|------|
| 2 | 关键指标的 95% CI 都有，且主要风险源识别正确 |
| 1 | 有 CI 但风险源识别不完整 |
| 0 | 没有 CI 或风险源 |

### 6. 变化趋势（2 分）

| 分数 | 标准 |
|------|------|
| 2 | 硬件价格/性能/效率的趋势都有具体数字，且预测合理 |
| 1 | 有趋势但缺少具体数字 |
| 0 | 没有趋势分析 |

## 总分

- **满分 20 分**
- **及格线 12 分**（60%）
- **优秀线 16 分**（80%）

## 评分流程

1. **逐项打分**：每个维度 0-4 分（维度 5/6 是 0-2 分）
2. **合计**：总分 = 维度 1-6 分数之和
3. **备注**：记录关键扣分点（如「缺少 XX 指标的误差范围」）

## 示例评分

假设研究 prompt 生成的结果：
- 缺失信息识别：3 分（大部分黑盒节点识别出，但优先级排序有误）
- 矛盾挖掘：4 分（所有主要矛盾都挖出，验证路径清晰）
- 推理与计算：3 分（大部分关键指标有计算链，但缺少误差范围）
- 产投比评估：4 分（所有方案的产投比计算正确，排序正确）
- 风险与方差：2 分（关键指标的 95% CI 都有，主要风险源识别正确）
- 变化趋势：2 分（硬件价格/性能/效率的趋势都有具体数字，预测合理）

**总分 = 3 + 4 + 3 + 4 + 2 + 2 = 18/20**（优秀）

**备注**：
- 缺失信息识别扣分：优先级排序有误（次要因素排在瓶颈之前）
- 推理与计算扣分：缺少 XX 指标的误差范围
