## 关键发现

1. **CON-N 对称契约有效**：C5 从 R0.1 的 1.67 回到 2.00，R0.1 里 run2 只挖 1 个矛盾的失败模式被兜住。
2. **COST 紧凑化目标未达成**：设计意图是省 token 还给 C2（逐卡对比），但 run1/run2 的 C2 仍停在 1——说明 C2 退化不是 COST 展开说明挤占的，而是模型本身不擅长逐卡数值对比（注意力竞争假说部分推翻）。
3. **方差爆炸是新问题**：σ 0.47→3.30。run3 英文输出+占位符+第3节塌缩成 "(Calculations from draft)"——契约遵循度随 run 波动，prompt 约束没有硬性保证。
4. **中位数视角**：R0.2 median=17 > R0.1 median=16 > R0 median=16。如果接受"跑多次取中位"的评测协议，R0.2 是最优变体。
