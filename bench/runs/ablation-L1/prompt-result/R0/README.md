## 内容

R0 是 research-prompt 项目的**完整契约版 prompt**（21 零件），仿照 decomp C0，用于将研究问题分解为完备、正交、可验证路径。

**零件**（21 个）：
1. 草稿节（scratch space）
2. 研究问题定义（根节点）
3. 研究路径（文件夹式分层）
4. 完整/不重叠两检（coverage + orthogonality check）
5. 黑盒标注（查不到/量不出/需要实测）
6. 矛盾挖掘（节点间张力/冲突）
7. 验证问题清单（每个矛盾带验证路径）
8. 瓶颈标注（占成本/时间/效率的关键因素）
9. 单位检查（所有计算单位一致性）
10. 误差传播（关键指标 ±%）
11. 计算链（公式+代入+结果）
12. 产投比（产出/投入）
13. 风险与方差（95% CI）
14. 变化趋势（价格/性能/效率）
15. 验收标准（每个节点可验证）
16. 递归到原子（每个节点可执行）
17. 阶段边界（正交+覆盖）
18. 空缺清单（未覆盖的维度）
19. 依赖关系（节点间依赖）
20. 并行标注（可并行的节点）
21. 执行级原子化（最小可执行单元）

**是否指定候选硬件/权重精度**：❌（不包含候选硬件列表 + 权重精度，由 subagent 自行调研）
