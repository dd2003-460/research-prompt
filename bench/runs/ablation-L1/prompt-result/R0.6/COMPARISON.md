## 最终结论

**R0.3 是 qwen3.8-27b 上的最优 prompt 变体，消融实验到此终止。**

证据链：
1. R0.3 的三防崩机制（语言锁定/占位符FAIL/逐卡表）在 ×3 run 中全部生效，σ=0.94 受控。
2. 任何在此基础上叠加新契约的尝试（R0.5 加 S3、R0.6 加 S3+C2）都引入了 30-100% 的崩塌概率。
3. R0.4 证明 S3 SELF-CHECK 方向正确（遵循时 S3 1→2），但无法保证遵循。
4. 根因不是 prompt 设计——是 qwen3.8-27b 对长 prompt 多指令同时遵循的能力有硬上限。模型会随机"忘记"部分指令，且无法通过重复/强调/惩罚条款消除。

## 后续提升路径（非 prompt 层面）

- 换更强的执行模型（如 70B+ 或 API 模型）可突破此边界
- 分步执行（先出结构再填内容）可能比单 prompt 多契约更稳定
- 外部验证器（跑完后检查契约是否满足，不满足则重试）比 prompt 内约束更可靠
