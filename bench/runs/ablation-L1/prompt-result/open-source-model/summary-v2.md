## 3 run 关键结论（研究内容本身，3/3 收敛）

**瓶颈（3/3 一致）**：显存容量（8bit 27B+64K KV≈43GB，消费单卡无一满足）> 价格波动 > 带宽；20 tok/s 硬约束接近不 bind（4bit 需 ~300 GB/s，8bit 需 ~860 GB/s）。

**排序共识（3/3 一致）**：
1. 3090×2（二手，8bit）≈ $0.018–0.020/验收任务
2. 4090（4bit 极限）≈ $0.024–0.027
3. 5090（4bit）≈ $0.032
4. M3 Ultra 256GB（8bit）≈ $0.075–0.08
5. A100×2 ≈ $0.17（出局）

**矛盾/未解**：①4bit 通过率 vs 速度收益（run3 给出 <76% 反超阈值）②并发 N 未定义（N≥3 结论翻转）③二手 3090 价 ±20% ④4090 单卡放不下 64K FP16 KV（仅 run1 显式点出，硬矛盾已解）⑤prefill 缓存重建风险（仅 run2 讨论）。

**对比结论**：decomp C0 比开源自由研究高 6.34 分，远超 2σ（≈1.16）→ **差异显著**。差距主要来自结构分（C0 的契约强制树形分解 S1/S3 到位）与 C3/C4（系统 TCO、保值型号谱系），而非 C5（C0 的 C5=1.67 仅略高于开源 1.33）。

## 关键洞察

1. **C0 契约的价值被证实且量化**：+6.34 分、>5σ 显著。最大贡献是结构分——自由研究的 3 个 run 全在 S1（树形分层）/S3（不重叠自检）/S4（一日实测）拿到 1 分，说明「自由发挥」不会自发长出可逐级展开的树和显式自检；契约强制项恰好补在这里。
2. **内容侧开源不弱**：C1（场景分离）三 run 全 2 分、C2 全 1 分，说明 Llama/Qwen 级模型「自由思考」就能正确建模 prefill/decode 双瓶颈，C0 的增益主要在结构纪律与 TCO/保值这类「需要契约点名才会做」的维度。
3. **C5 区分度有限**：run1 靠「标注已解/未解+验证路径」拿到 2，run2/3 矛盾挖得一样多但没逐项标注只得 1。提示 R0 契约若要强化 C5，应显式要求「每个矛盾标注状态+验证路径」，而非仅要求「列矛盾」。
4. **σ 对比**：开源 σ=0.58 与 C0 σ=0.58 相当，说明两组的 run 间稳定性同级别；C0 的高分是系统性偏移，不是单次运气。
5. **评分一致性教训**：旧版评分用错维度（「完整性/正交性/原子性/草稿深度…」）且全给 19/20，掩盖了真实差距（13.33 vs 19.67）。**评分维度必须与 rubric 判据逐字对齐**，否则 ablation 的 Δ 结论会被虚高分数污染。
