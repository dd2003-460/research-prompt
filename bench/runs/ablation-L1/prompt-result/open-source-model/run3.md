# run3 — 开源最强模型风格自由研究（独立 run，不参考 run1/run2）

## 0. 草稿思考（自由展开）

先想：27B、64K、90:9:1、20 tok/s、通过率<100%。

第一反应：前缀缓存命中 90% 意味着大部分输入不用重算，prefill 只算新 9%（5760 tok）。decode 640 tok 是纯带宽活。所以任务时间 ≈ prefill(小) + decode(640 tok / 速度)。decode 速度由"每 token 要读多少字节"决定：权重 + KV。

第二个反应：20 tok/s 硬约束。每 token 读 ~15GB(4bit) 的话，需要 300 GB/s 带宽。单张 3090(936 GB/s) 就 6 倍余量。**这个约束太松了，几乎不 bind**——除非用 8bit 或 KV 特别大。等等，8bit 权重 27GB + KV 16GB = 43GB/token 读量？不对，KV 是每次读全部 16GB，所以 8bit 每 token 读 ~43GB，20 tok/s 需要 860 GB/s——单卡 3090 勉强，4090(1008) 够，3090×2 很够。

第三个反应：成本 = 硬件摊销 + 电费。任务只跑 20-30 秒，电费 ~$0.002，硬件摊销主导。所以**本质问题是：什么硬件最便宜地满足"放得下 权重+KV 且 decode≥20tok/s"**。

## 1. 候选硬件（自调研）

显存需求（64K KV）：
- 4bit 权重 14GB + KV 16GB(FP16)/8GB(FP8) = 22–30GB
- 8bit 权重 27GB + KV 16GB = 43GB

| 硬件 | 显存 | 带宽 | 能否 8bit 64K | 4bit decode 估 | 价格 |
|------|------|------|------|------|------|
| 3090×2 NVLink | 48 | 1872 合计 | 勉强(43GB) | ~50-60 tok/s | $1500 二手 |
| 4090 | 24 | 1008 | ❌ | ~65 tok/s(4bit极限) | $1800 |
| 5090 | 32 | 1792 | ❌(35GB>32) | ~100 tok/s | $2500 |
| 3090×4 | 96 | 3744 | ✅ 宽裕 | ~80 tok/s | $3000 |
| M3 Ultra 256GB | 256 | 819 | ✅ 巨宽裕 | ~55 tok/s | $4k-9k |
| A100 80GB | 80 | 2039 | ✅ | ~70 tok/s(8bit ~40) | $8k 二手 |
| L40S 48GB | 48 | 864 | 勉强(43) | ~45 tok/s | $4k |

**20 tok/s 检查**（8bit，每 token ~43GB）：
- 单卡需 ≥860 GB/s → 4090/5090/A100 单卡 OK，3090 单卡(936) 极限 OK
- 3090×2、M3 Ultra 均轻松
→ **8bit 下 20tok/s 也基本不 bind**。真正的硬约束是显存容量。

## 2. 任务时间与成本

单任务（假设 N=1 并发）：
- prefill 5760 tok：3090×2 ~4-5s；4090 ~4s；M3 Ultra ~10s
- decode 640 tok：@50 tok/s = 12.8s；@65 = 9.8s
- 墙钟 ≈ 15–22s

成本 = 摊销 + 电费：
- 摊销 = 卡价/10万任务：3090×2 $0.015；4090 $0.018；5090 $0.025；M3 Ultra $0.07–0.09；A100 $0.08
- 电费 ≈ 0.002–0.004
- **3090×2 8bit ≈ $0.019；4090 4bit ≈ $0.024；5090 4bit ≈ $0.032；M3 Ultra 8bit ≈ $0.08**

通过率惩罚（8bit ×1.05，4bit ×1.15–1.25）后：
- **3090×2 8bit ≈ $0.020 ← 最优**
- 3090×2 4bit ≈ $0.022（通过率风险大）
- 4090 4bit ≈ $0.027

## 3. 矛盾/张力

1. **8bit 显存墙**：27+16=43GB，消费级单卡无一满足（4090=24, 5090=32），必须双卡(3090×2)或专业卡。这把"最便宜单卡"直觉打掉。
2. **并发数 N**：N 流 → KV ×N。N=3 时 3090×2 的 48GB 装不下 8bit（43+KV余量）→ 需要 3090×4 或 M3 Ultra，**结论随 N 翻转**。题目没说 N，是最大黑盒。
3. **4bit 通过率**：省显存+提速，但通过率 80% vs 8bit 95% → 重做成本。若 4bit 通过率 <76%，则 4bit 总成本反超 8bit。未实测，黑盒。
4. **二手价波动**：3090 $700–1000/张 ±20%，直接影响第一名的绝对值（不改变排序除非波动 >30%）。

## 4. 结论

**推荐**：3090×2（二手 NVLink，8bit 权重 + FP8 KV）≈ **$0.02/验收任务**。
- 瓶颈：显存容量（不是带宽，20tok/s 不 bind）
- 矛盾：N 并发未定义（N≥3 翻转为 3090×4/M3 Ultra）；4bit 通过率未实测
- 置信度：**0.6**（架构参数假设、N 未知、通过率估计三处软肋；若 N=1 固定则升 0.75）
