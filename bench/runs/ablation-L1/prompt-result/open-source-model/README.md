## 3 run 关键结论汇总

### 瓶颈（3/3 一致）
- **显存容量是硬约束**（8bit 27B + 64K KV ≈ 43GB，消费级单卡无一满足）
- **20 tok/s 硬约束接近不 bind**（4bit 需 ~300 GB/s，8bit 需 ~860 GB/s，主流卡带宽均够）
- 电费占 ~10-20%，硬件摊销主导（任务墙钟仅 15-25s）

### 排序共识（3/3 一致）
1. **3090×2（二手，8bit）≈ $0.018-0.020/验收任务** ← 3 run 均推此
2. 4090（4bit 极限）≈ $0.024-0.027
3. 5090（4bit）≈ $0.032
4. M3 Ultra 256GB（8bit）≈ $0.075-0.08
5. A100×2 ≈ $0.17（最贵但最快，出局）

## 与 R0 契约版（待实跑）的初步对比印象

1. **结构差异**：开源模型自由发挥 → 叙事式（问题→路径→矛盾→结论），无强制节点字段（PARENT/IN/OUT/KIND/SHARE/BOUND/TEST）、无 SHARE 加总=1.00 校验、无正交 RES 检查、无停止条件表引用。R0 强制 21 零件契约，预期会产出更结构化但可能更冗长的输出。
2. **瓶颈识别**：3 run 自由发挥即一致收敛到"显存容量 > 带宽 > 20tok/s 不 bind"，且排序稳定（3090×2 第一）。说明**此问题瓶颈可发现性高**，R0 契约的主要价值不在"找对瓶颈"而在"强制覆盖盲区"（如 N 并发、prefill 重建）。
3. **矛盾挖掘**：自由 run 自然挖到 3-4 个矛盾（4bit 通过率、N 并发、显存墙、二手价），但未用 CON 结构化格式、未给 IMPACT ±%、未给 VERIFICATION 动作句。R0 的 CON 格式 + IMPACT 量化预期会更完整。
4. **黑盒处理**：自由 run 把 N 并发、4bit 通过率当"不确定性"提一句即过；R0 要求 blackbox 必须写 TEST + 估计区间 + "取区间两端 BOTTLENECK 会不会变"——后者是 R0 独有强制项，自由 run 全未做。
5. **计算链**：自由 run 有公式+代入+结果，但未标 [F]/[M]/[S]/[E] 来源标记、未给 95% CI（只给 ±% 估计）。R0 强制来源标记 + 误差区间，可验证性更强。
6. **预期评分差距**：结构维度（20 分制 10 分）自由 run 预计 4-6/10（无强制字段、无校验）；内容维度（10 分）预计 7-8/10（瓶颈对、矛盾实、计算链基本完整）。总分预计 11-14/20，vs decomp C0 基线 19.67。R0 实跑若达 17+ 则证明契约对研究任务同样有效。
7. **风险**：R0 的 21 零件可能让模型陷入"填表"而弱化"洞察"——自由 run 的"20tok/s 不 bind"是关键 insight（直接砍掉带宽维度），R0 契约下该 insight 可能被埋在节点字段里。需看 R0 实跑是否在 REASON 字段保留该 insight。
