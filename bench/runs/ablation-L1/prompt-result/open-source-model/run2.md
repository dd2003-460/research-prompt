# run2 — 开源最强模型风格自由研究（独立 run，不参考 run1）

## 0. 问题拆解

本地 27B，64K 上下文，90:9:1 缓存命中，decode ≥20 tok/s/并发流，求 $/验收任务最低。

第一步：把任务拆成 prefill 与 decode 两阶段，分别定瓶颈类型。
- prefill：新输入 = 9% × 64K = 5760 token（前缀 61440 命中缓存不重算）→ compute-bound
- decode：输出 = 1% × 64K = 640 token → memory-bound
- 墙钟 = t_prefill + 640/v_decode

## 1. 候选硬件调研（自行调研，不依赖给定列表）

考虑维度：显存容量（权重+KV 是否放得下）、带宽（decode 速度）、算力（prefill 速度）、价格、二手可得性。

**KV cache 估算**：27B 级别模型（Llama 风格，64 层 GQA-8）KV ≈ 16GB @ FP16 / 8GB @ FP8。
**权重**：4bit ≈ 14GB，8bit ≈ 27GB，FP16 ≈ 54GB（27B 放不下单消费卡）。

| 硬件 | 显存 | 带宽 | 价格 | 可行性 |
|------|------|------|------|--------|
| 4090 | 24GB | 1008 GB/s | ~$1800 | 4bit 14+8(FP8 KV)=22GB 极限可行；8bit 不行 |
| 3090×2 | 48GB | 2×936 | ~$1400 二手 | 4bit/8bit 都从容，8bit 27+16=43GB 刚好 |
| 3090×4 | 96GB | 4×936 | ~$3000 | 支持高并发（KV ×N） |
| 5090 | 32GB | 1792 GB/s | ~$2500 | 4bit 宽裕，8bit 27+8=35GB 超 32 略不行 |
| M2/M3 Ultra (256GB) | 256GB | 800 GB/s | $4k–9k | 并发能力强，单流速度中等 |
| A100 40GB×2 | 80GB | 2×1555 | ~$16000 二手 | 8bit 宽裕，速度顶级但贵 |
| L40S×2 / A6000×2 | 96GB | 2×864 / 2×768 | $8k–12k | 中间档 |

**prefill 速度**（5760 token，有效算力）：
- 4090 ≈ 90 TFLOPS → ~3.5s
- 3090 ≈ 35 TFLOPS → ~9s
- 3090×2（两卡并行 prefill）→ ~4.5s
- M3 Ultra ≈ 30 TFLOPS → ~10s
- 5090 ≈ 130 TFLOPS → ~2.5s

**decode 速度**（每 token 读权重+KV）：
- 4bit：3090×2 ≈ 936×2/15 ≈ 125 理论 → 实测 50–70 tok/s；4090 ≈ 60–70；5090 ≈ 100+
- 8bit：读 27GB+KV → 3090×2 ≈ 30–40 tok/s；A100×2 ≈ 50+

**20 tok/s 约束**：所有候选 4bit 单卡都满足；8bit 下单卡 3090（936/29≈32）刚好满足。**约束只在 8bit 单卡老硬件上 bind**。

## 2. 成本建模

每验收任务成本 = (摊销 + 电费) / 通过率

摊销 = 卡价 / 寿命任务数。假设寿命 10 万任务（3 年 × 每天 ~90 任务，任务墙钟 ~20s）。
- 3090×2: $1400/1e5 = $0.014
- 4090: $1800/1e5 = $0.018
- 5090: $2500/1e5 = $0.025
- M3 Ultra 256: $7000/1e5 = $0.07
- A100×2: $16000/1e5 = $0.16

电费：单任务 20–25s × 350–700W × $0.1/kWh ≈ $0.002–0.005（占 ~10–20%，不可完全忽略）。

**通过率**（估计，未实测）：
- 8bit：~95% → 惩罚 ×1.05
- 4bit：~80–90% → 惩罚 ×1.11–1.25

**$/验收任务**：
- 3090×2 + 8bit: ($0.014+$0.003)×1.05 ≈ **$0.018**
- 3090×2 + 4bit: ($0.014+$0.003)×1.15 ≈ **$0.019**
- 4090 + 4bit: ($0.018+$0.003)×1.15 ≈ **$0.024**
- 5090 + 4bit: ($0.025+$0.003)×1.15 ≈ **$0.032**
- M3 Ultra + 8bit: ($0.07+$0.002)×1.05 ≈ **$0.075**
- A100×2 + 8bit: ($0.16+$0.003)×1.05 ≈ **$0.17**

## 3. 关键矛盾

1. **8bit 显存 vs 4bit 通过率**：8bit 质量稳但显存需求 27+16=43GB，单消费卡（4090/5090）放不下 → 被迫 4bit 或双卡。3090×2 是唯一"便宜+8bit 可行"组合。
2. **二手 3090 价格波动**：$700–1000/张，±20% 波动直接改变排序头部。
3. **并发数未定义**：题目说"每个并发流 ≥20 tok/s"，如果 N=4，KV 需要 4×16GB=64GB → 3090×2 出局，需要 3090×4 或 M3 Ultra，结论翻转。
4. **prefill 占比被低估？**：如果任务不是连续会话（前缀缓存需重建），prefill 从 5760 变 64K，时间 ×11，任务墙钟 ~2min，电费占比升至 ~30%。但题目明确"前缀可被缓存"，按命中算。

## 4. 结论

**推荐**：3090×2（二手，8bit）≈ $0.018/验收任务，比 4090 便宜 25%，比 5090 便宜 44%，比 M3 Ultra 便宜 4×。
**瓶颈**：显存容量（决定 8bit 可行性）> 价格波动（二手）> 带宽（20tok/s 不 bind）。
**置信度**：0.65 — 通过率纯估计（±10pp 可翻 4bit/8bit 排序），N 并发未知（N>2 时结论翻转），二手价 ±20%。
