# R0.3C4 - C4 知识注入（保值参考表）

# origin: ai

## 动机

T33 (R0.3V) 证明 two-pass verification 对分析深度 rubric 无效。
SUMMARY.md 建议：C4 需知识注入（prompt 附录加 GPU 保值参考表），预计 C4 从 1→2。
本变体测试：在 R0.3 prompt 末尾追加保值参考表，能否提升 C4 且不破坏其他维度？

## 设计

- 唯一改动：prompt 末尾追加「附录：GPU 保值参考表」（8 个型号的保值性+说明）
- 执行参数与 R0.3 baseline 完全相同：qwen3.8-27b, temp=0.7, max_tokens=32000
- n=3 runs

## 判读

**假设被强烈否定。** 追加 1.2KB 保值参考表导致总分暴跌 7 分，且全部来自结构分崩塌。

### 根因分析

1. **格式契约失效**：run2 完全没有输出五节结构（0 个 `##` 标题）。模型把 29K 字符的 budget 花在了"草稿"式自由发挥上，最终没有按格式输出。R0.3 的 prompt 有硬性格式要求（"你的回答必须且只能由五节组成"），但追加附录后，模型的注意力被分散——它开始"研究"而不是"按格式写报告"。

2. **C4 没有提升**（1.00 → 1.00）：模型确实引用了保值信息（run1 提到 A100 保值率高、M 系转卖难），但没有达到 rubric 要求的"具体到型号对比"深度。给表 ≠ 模型会做对比分析。

3. **C5 崩塌**（2.00 → 0.33）：run2/run3 完全没有导出矛盾点。模型忙于计算和罗列，没有做"从分解中导出可验证矛盾"这一步。

4. **方差引入**：σ 从 0 → 0.82。三个 run 的行为差异巨大（run1 有结构但 C5 弱，run2 无结构，run3 有结构但 C5 零）。

### 为什么 R0.3 是 18/20 σ=0 而加了 1.2KB 就崩？

R0.3 的 prompt 是一个精密的格式机器：核心规则 + 五节硬约束 + 逐卡表格要求 + 停止条件表。每个 token 都在服务"让模型按格式输出"这个目标。追加附录打破了这个平衡——模型看到"参考框架"后切换到了"研究模式"而非"报告模式"，格式契约整体失效。

## 结论

**Knowledge injection via prompt appendix is destructive for format-constrained prompts.**

正确路径不是"给模型更多信息"，而是：
1. 把保值信息嵌入现有格式节点（如在第 3 节 CALCULATIONS 的 TCO 表里加一列"残值率[E]"）
2. 或者改 rubric（C4 不再要求"具体到型号对比"，改为"提及保值概念并给出至少一个型号示例"）
3. 或者换更强模型（70B+ 可能同时处理格式约束+知识整合）
