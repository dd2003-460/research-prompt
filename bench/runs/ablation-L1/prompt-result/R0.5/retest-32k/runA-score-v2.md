## 判读

runA 证明 R0.5 prompt 在足够 max_tokens 下**可以**产出合格研究（16/20），
但结构深度（S1=1）不如 R0.3（S1=2）——SELF-CHECK 契约提升了 S3 但没提升拆解深度。
R0.5 的主跑崩塌（0-6 分）主要是 max_tokens 配置问题 + 模型指令遵循随机性的叠加，
不是 prompt 设计本身的缺陷。
