## 关键发现

1. **R0.3 仍是当前最优定版**：mean 17.33 最高，σ 0.94 受控。
2. **R0.5 全面崩塌**：三个 run 全部停在草稿阶段，中文比例 6%/12%/8%，SELF-CHECK 零遵循。模型把整个输出当草稿处理了，结尾写着"Ready to write"/"Proceeding to formal output"但没写。
3. **根因不是 prompt 设计，是模型能力边界**：qwen3.8-27b 对长 prompt 的指令遵循不稳定。R0.3 的三防崩机制在 R0.5 里完全没生效——同样的语言锁定、同样的占位符 FAIL，在 R0.3 能防住，在 R0.5 防不住。这说明模型的指令遵循有随机性，不是 prompt 能完全控制的。
4. **S3 契约的价值**：R0.4 证明 S3 SELF-CHECK 在遵循时能把 S3 从 1 提到 2，方向正确。但需要防崩基线保护，而防崩基线本身也不稳定。
5. **结论**：继续加契约边际收益递减，模型能力是硬约束。R0.3 是当前 qwen3.8-27b 的最优 prompt 变体。进一步提升需要换更强的判官模型或执行模型。

## 消融实验总结

六个版本跑完，核心结论：
- **CON-N≥2 契约**（R0.1 引入）：持续有效，C5 在所有版本稳定 ≥1.67。
- **语言锁定**（R0.3 引入）：在 R0.3 有效（全中文），在 R0.5 失效（英文漂移）——模型随机性。
- **占位符 FAIL**（R0.3 引入）：在 R0.3~R0.4 有效（C3=2.00），在 R0.5 失效（run3 出现"待定"）。
- **逐卡表**（R0.3 引入）：在 R0.3 让 C2 到 1.67，在 R0.4 run3 拿到满分 2。
- **S3 SELF-CHECK**（R0.4 引入）：方向正确（S3 1→2），但需要防崩保护。
- **模型能力边界**：qwen3.8-27b 的指令遵循有 ~20% 概率全面崩塌（R0.4 run1, R0.5 ×3），prompt 无法完全控制。
