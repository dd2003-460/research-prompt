# R0.3 - 防崩版（语言锁定 + 占位符 FAIL + 逐卡时间表）

# origin: ai

## 动机

R0.2 结果分裂：run1/run2=17（三版单 run 最高），run3 崩到 10（英文输出+
$X/$Y 占位符+第3节塌缩），σ 爆到 3.3。根因分析：
1. prompt 无语言锁定 → run3 漂成英文，格式契约整体失效
2. COST 因子允许查不到就空着 → 模型填了占位符
3. C2 逐卡对比无显式表格要求 → 模型不给数值对比

R0.3 三个最小改动对症：
1. 开头加【输出语言】全程中文，禁止切英文
2. COST 因子禁止 $X/$Y/待定占位符，查不到给估计值 [E][±%]，出现即作废
3. 第3节强制逐卡 prefill 时间 vs decode 延迟对比表，缺表 C2 不得分

## 验收标准

- 无离群点：3 run 全部 ≥14（压 σ < 1.5）
- C2 ≥ 2（逐卡时间表出现且带数值）
- C3 ≥ 2 且 C4 ≥ 1 不回退（无占位符）
- mean ≥ 17（超过 R0 基线 16.00 和 R0.1 的 16.33）
