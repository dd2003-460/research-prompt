## 结论

1. **研究 prompt R0 契约版 17.67/20**，vs qwen3.8-bare 裸 prompt 9.00/20，**Δ=+8.67 高度显著**（2σ≈0.67）
   - 提升来源：结构纪律（树形分层/不重叠自检/黑盒+区间+一日实测）+ 内容深度（cache 分离/prefill+decode 逐卡/矛盾状态标注）
   - 裸 prompt 会自行填充错误前提（LLaMA-3 架构假设/3090 BW 760 错误/2000 tokens 打包），契约版的约束价值不仅是结构，更是**防止模型幻觉填充**
2. **R0 vs decomp C0 Δ=−2.00**，研究 prompt 与 decomp prompt 是不同维度的优化
   - decomp 侧重树形分解/完备性（S 分高），研究 prompt 侧重研究路径/矛盾挖掘（C5 高）
3. **C5 矛盾挖掘**：R0 2.00 / decomp C9-plain 2.00 并列最高；qwen3.8-bare 仅 1.00（矛盾数够但缺状态标注）
4. **qwen3.8-bare 3 run 雷同**（σ=0.00），裸 prompt 下模型输出高度稳定但质量低
5. **C4 保值全 0**（R0 和 qwen3.8-bare 均未做保值/二手残值分析），是研究 prompt 的共同短板
6. **C3 全 1**（R0 运维未分解），TCO 拆解深度可提升
