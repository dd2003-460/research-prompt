## 正交性核对

- P0-P5 正交：建档 → 原型 → 实跑 → 评分 → 对标 → 汇总
- P1 研究 prompt 原型 = 白话版 + 完整契约版（正交：白话版简单，契约版严格）
- P2 3 run = 3 次独立实跑（正交：每次独立，不共享上下文）
- P3 rubric 评分 = 结构（10 分）+ 内容（10 分）（正交：结构看格式，内容看深度）
- P4 对标 = decomp + 开源（正交：decomp 是分解，开源是研究）
- P5 汇总 = 跨阶段汇总（依赖 P0-P4）

## 空缺清单

- 研究 prompt 完整契约版（21 零件，仿照 decomp C0）
- 20 分制 rubric（结构 10 分 + 内容 10 分）
- 3 run 实跑结果
- 对标 decomp/开源的结果
- GitHub 仓库（dd2003-460/research-prompt-bench）
- Arena 任务书（评判各种 AI 研究能力）
